Proyecto: Eco vecinos. 
Para ejecutar el programa directamente en la página web se usa el link de la página 
http://127.0.0.1:8000/ (Se debe tener abierto el vs o cualquier otro programa para visualizar el código, escribiendo en el terminal de vs ¨python manager.py runserver¨)
Una vez ingresado en la página se puede crear una cuenta para guardar tu información y poder acceder a las funciones, en caso de no desear iniciar sesión no impide el funcionamiento y el acceso a las funciones de la página web, cómo el mapa o el filtro de este.
Cuando se desee buscar usando un filtro se debe volver a ingresar una ubicación para que se actualice la búsqueda con el nuevo filtro, para luego ingresar la dirección original y ver los puntos deseados
